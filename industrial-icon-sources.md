# Industrial Icon Sources

The industrial icon system uses original compositions derived from the **Ultimate free icons** collection by Streamline, supplied through Iconify. The source collection is licensed under **Creative Commons Attribution 4.0 International (CC BY 4.0)**. The public footer includes the required Streamline attribution.

The final `gear-chip-mark.svg` motif combines an Apache 2.0 Material Design Icons gear and chip with original circuit-trace connectors. It replaces the earlier `gear-circuit.svg` experiment so the automation mark reads as a clean industrial system rather than two unrelated symbols.
