# GitHub Project Import Notes

## Selected repositories

Two public repositories owned by Mohammed Bajhaw were selected for import into the engineering portfolio. Their project descriptions, architecture, and technical terms are taken from their public repository documentation.[1] [2]

| Portfolio title | Source repository | Verified scope |
|---|---|---|
| Autonomous Cave Exploration Drone | [`drone-navigation`](https://github.com/MohammedBajhaw/drone-navigation) | A ROS 2 autonomous drone system for GPS-denied cave, tunnel, and mine environments. The repository documents 3D D* Lite path planning with OctoMap, frontier-based exploration, obstacle avoidance, TF broadcasting, and tunnel-flight control. |
| Robotic Arm CAD, Simulation & Control | [`Robotic-Arm-SolidWorks-Matlab`](https://github.com/MohammedBajhaw/Robotic-Arm-SolidWorks-Matlab) | A SolidWorks-to-Simscape Multibody workflow containing an educational 2-DOF arm and an advanced 5-DOF model. The repository documents forward/inverse kinematics, closed-loop PID control, and mechanical CAD source files. |

## Import decisions

Both projects will be marked as completed portfolio work and include a durable **View source on GitHub** link in the project detail page. The arm repository does not include a ready-to-use showcase image; the imported record will remain media-ready so the owner can upload a real screenshot or rendering from the administration console later. The drone repository includes many simulation assets, but none was selected automatically as a project cover because those files are primarily environment textures and model resources rather than a curated project visual.
