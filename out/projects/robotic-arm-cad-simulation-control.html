Overview

This project connects detailed SolidWorks assemblies with MATLAB Simscape Multibody for dynamic simulation of articulated robotic arms. It includes a 2-DOF learning model for control fundamentals and a more advanced 5-DOF model for spatial manipulation.

The repository covers CAD source models, forward and inverse kinematics, automated setup scripts, rigid-body dynamics, and closed-loop PID trajectory tracking.

System stack

  • SolidWorks
  • MATLAB
  • Simulink
  • Simscape Multibody
  • Inverse Kinematics
  • PID Control

Outcomes

  • 2-DOF educational model for PID tuning
  • 5-DOF Simscape Multibody model with inverse kinematics
  • SolidWorks mechanical assemblies and component source files
