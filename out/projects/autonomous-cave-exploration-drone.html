Research project

Autonomous Cave Exploration Drone

An autonomous UAV exploration system for mapping, safe navigation, and frontier-based discovery in enclosed GPS-denied environments.

ROS 2Autonomous UAV3D Path PlanningFrontier ExplorationGPS-Denied Navigation
View source on GitHub ↗

Overview

Built for caves, tunnels, and similarly constrained environments, this ROS 2 project combines real-time 3D environment mapping with autonomous route selection and obstacle-aware flight control.

The system integrates a 3D D* Lite planner with OctoMap, frontier-based exploration with recovery logic, odometry-to-TF broadcasting, and a look-ahead tunnel-flight controller.

System stack

  • ROS 2 Humble
  • C++
  • Python
  • OctoMap
  • DSP D* Lite
  • MAVLink

Outcomes

  • 3D D* Lite planning with OctoMap integration
  • Frontier-based autonomous exploration with goal recovery
  • Look-ahead tunnel flight controller and TF mapping pipeline
