# Category Icons and Project Media Verification

The skills section now uses a single large, coloured engineering icon for each main discipline rather than an icon inside every individual skill tag. The category cards maintain their technical colour identity across desktop and mobile layouts while leaving the skill names visually quiet and easy to scan.
